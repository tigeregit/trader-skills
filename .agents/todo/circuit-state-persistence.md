# 熔断状态持久化

## 来源

100～1000 个 agent 共享无法快速更换的家庭 IP；网关重启不得清空封禁状态。

## 背景

当前熔断器仅存于内存。状态库异常时需全局失败关闭，并按
10 分钟、30 分钟、1 小时、6 小时、12 小时、24 小时的阶梯探测存储恢复，
不得通过重启绕过等待。

## 待办

- [x] 持久化各来源熔断状态和失败次数。
- [x] 实现独立安全标记与六档存储退避。
- [x] 存储异常时只服务缓存，不访问上游。
- [x] 使用 fake clock 验证时间边界、重启和 1000 并发单探针。
- [x] 验证 SQLite、标记和日志无 URL/Cookie/CSRF。
- [x] 更新设计与测试文档。

## 验收标准

- 403/429 和累计 5xx 熔断跨重启保留。
- 存储退避精确遵循 10m/30m/1h/6h/12h/24h，24h 为上限。
- 任一退避窗口内受控来源外网请求为 0，缓存仍可读。
- 状态库与安全标记同时异常时按 24h 失败关闭。
