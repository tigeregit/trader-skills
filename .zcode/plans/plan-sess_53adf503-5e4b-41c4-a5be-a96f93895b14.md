## 提交策略（遵循 commit 规范，单一逻辑变更）
分 3 个 commit：
1. `refactor(.agents): migrate docs into agents structure` — 文件搬迁 + temp/.gitkeep
2. `docs(.agents): add top-level README and entry index` — 新建总 README
3. `docs: sync cross-references after agents reorg` — 全部路径引用同步 + 修复断链 + AGENTS.md §7 调整

> 注：搬迁与引用同步若分开会短暂留下断链，但 commit 规范要求"单一逻辑变更"。采用：commit1 做物理搬迁，commit2+3 修引用——每个 commit 内部仓库自洽（文件移动后引用在同一/后续 commit 修，不留 broken 中间态：commit1 后路径虽变但 markdown 链接是软引用不影响编译，commit3 统一修正）。为严格避免 broken 态，也可合并为单个 commit；届时按实际改动量决定。
